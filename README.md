## Currently Building

### [Moonbase AI](https://moonbase.biz/) &nbsp;—&nbsp; Technology Commercialization Platform

A production AI platform serving university Technology Transfer Offices (TTOs). Moonbase ingests NSF/NIH grants, scores them across dimensions like market opportunity, IP white space, PI credibility, and TRL, and surfaces actionable commercialization intelligence — all built for **CMMC 2.0 Level 2** compliance in DoD-adjacent environments.

> `AWS ECS Fargate` &nbsp;·&nbsp; `PostgreSQL + pgvector` &nbsp;·&nbsp; `Neo4j` &nbsp;·&nbsp; `Next.js` &nbsp;·&nbsp; `Bedrock` &nbsp;·&nbsp; `Docker`
